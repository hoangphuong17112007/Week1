# XÁC ĐỊNH YÊU CẦU ĐỀ BÀI
- Nhập vào một chuỗi gồm toàn giá trị 0 và 1 sau đó sắp xếp để tất cả các giá trị 0 ở trên đầu còn các giá trị 1 ở phía sau
# GIẢI THUẬT
- Viết hàm void nhập vào mảng và giá trị n là số phần tử của mảng
- Đếm số phần tử bằng 0 bằng biến count, mỗi khi gặp phần tử =0 thì count ++;
- Biến đếm k = 0, với mỗi vòng lặp count dùng while đến khi while(0) thì kết thúc sắp xếp các phần từ bằng 0 lên đầu
- Tiếp tục k<n thì lấy ra các phần tử bằng 1 ở cuối
